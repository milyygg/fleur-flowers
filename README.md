## Как скачать и открыть у себя

1. Нажмите зелёную кнопку **Code** вверху страницы репозитория → **Download ZIP**.
2. Распакуйте архив.
3. Откройте файл `index.html` в браузере. Интернет не нужен: шрифты и фото лежат в папке.

## Что внутри

- `index.html` - страница
- `css/` - стили и шрифты
- `js/products.js` - каталог (100 товаров)
- `js/main.js` - корзина, фильтры, анимации
- `assets/` - фотографии и шрифты

Фотографии с бесплатного стока [Pexels](https://www.pexels.com/license/).

Технологии: HTML, CSS, JavaScript.
